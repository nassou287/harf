# Harf — حَرْف

Application personnelle pour apprendre à lire l'arabe, pas à pas.

**Ouvrir l'application : https://nassou287.github.io/harf/**
(sur iPhone : Safari → Partager → « Sur l'écran d'accueil »)

Ce dépôt contient uniquement la version publiée de l'application (fichiers prêts à servir).
Elle fonctionne entièrement dans le navigateur : aucune donnée de progression n'est envoyée
sur Internet, tout reste sur l'appareil de l'utilisateur.
